## Rule

README = orientation. ARCHITECTURE = system-level. `docs/technical` and `docs/design` = subsystem detail. Inline comments = implementation-level *why*.

No explanation should exist in two places. When editing, update the most specific document and reference it from higher levels instead of duplicating content.
